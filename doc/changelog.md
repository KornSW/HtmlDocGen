# Change log
This files contains a version history including all changes relevant for semantic versioning...

## Upcoming Changes

- **V2 (incompatible with 1.x):** dependency-free C# HTML template engine for net8.0 and net10.0 replaces the VB implementation; the net46 target, kSystemExtensions / ComponentDiscovery dependencies and the wkhtmltopdf runtimes were removed.
- **V2:** HTML-first directives u-for, u-if / u-else-if / u-else, u-block, u-include with parameters, layouts with u-slot / u-fill.
- **V2:** expression language with method calls, deterministic overload resolution, indexers, comparisons, Boolean operators and .NET format strings.
- **V2:** trusted and restricted member access policies, lazy sources, composite / file / embedded / memory template sources and located diagnostics.
- **V2:** canonical T4 composition template for embedding the engine as internal source code.
- **V2:** license changed to MIT + Commons Clause.
